# DSHQuant 使用指引（新手实操手册）

> 面向"第一次用这个系统"的人。每个功能都写清楚：**它是干什么的 → 在哪看 → 怎么操作 → 会看到什么**。
> 最后有一条**从零到下单、验证、回测的完整闭环**，照着做一遍就懂全貌了。
>
> 环境/部署细节见 [`本地部署记录.md`](本地部署记录.md)；系统原理见 [`/help`](http://127.0.0.1:8787/help)。

## 0. 先纠正三个最常见的误解

| 误解 | 事实 |
|---|---|
| "回测要先买入/要有持仓" | ❌ **不需要**。回测是拿历史行情重演策略规则（T+1 执行、扣佣金+印花税+滑点），和你的账户无关。它回答"这套规则过去行不行"，不回答"我手里这只怎么样"。 |
| "回测是拿我现在买的股票算的" | ❌ 回测的股票池由参数决定（例如按流通市值取前 300 只、或全市场），不是你的持仓。你的持仓看 [`/holdings`](http://127.0.0.1:8787/holdings)。 |
| "系统推荐的股票就是让我买" | ❌ 只有 **Pitch 卡片经你点"买入"审批**后才会出现在"今日买入指令"里；机会池、参考 L1 都**不产生指令**。 |

## 2. 系统分层：一张图看懂

```
L0 择时（/timing_dash）            市场环境打分 → 决定总仓位（防守档不买）
   ↓
机会池（/pitch → 参考 L1）         全市场 7 类机会扫描，1000+ 条 → 只是"证据"，不可买
   ↓ 三重过滤 + 分档
Pitch 长线（/pitch 长线 Tab）       ≤12 只，人工审批 → 审批后进"今日买入指令"
Pitch 短线（/pitch 短线 Tab）       ≤6 只，情绪/资金线，必须带 ATR 止损（平行支线）
   ↓
三层池 L1→L2→L3（纪律层）          观察池→候选池→决策池：今天到底买什么、买多少
   ↓
持仓（/holdings）                  买入后在这里管：盈亏、止损、止盈、卖出
   ↓
远期池（/pitchtrack）              入池后 T+1/5/20/60 实际表现 → 反过来给类型打分
```

> 辅助模块：`/factors` 因子池 · `/backtest` 回测档案 · `/etf` ETF 映射 · 五福轮动（门户）· `/report` 日报 · `/data` 数据资产 · `/control` AI 控制台。

## 3. 每个功能怎么用

### 3.1 门户 `/`（每天第一眼看这里）

**作用**：一屏看今天该不该动手。包含 KPI（Pitch 数/机会数）、择时档位、实时行情、五福轮动、API 状态。

**怎么做**：打开就是，60 秒自动刷新。右上角「实时更新」按钮 = 手动触发整条数据管道（约 20–38 分钟，见 §4）。

**看什么**：
- 择时颜色：🟢 适合买入 / 🟡 谨慎 / 🔴 不适合（**红色时不要新建仓**）
- 实时行情：涨跌家数、涨停数、成交额
- 五福轮动：A 股弱时提示加配黄金/债券（当前 9 只全球资产动量面板）

### 3.2 择时 `/timing_dash`（L0，决定仓位）

**作用**：政策/宏观/情绪/宽度四维打分 → 总仓位建议。

**怎么做**：只读页面，60 秒刷新。

**看什么**：总分（如 43.3 = 🟡 谨慎买入）、四维分解、历史曲线、日历窗口（11 月 Q4 核心 +5 分）。

> 口诀：**L0 红档 = 只看不买**；黄档 = 只用小仓；绿档 = 正常执行 Pitch。

### 3.3 决策页 `/pitch`（核心工作台）

这个页面有 5 个 Tab，按"产生指令的顺序"看：

#### ① 今日买入指令（顶部折叠块）
- **作用**：把"长线 + 短线"待审批卡片聚合成一张清单，和下方卡片同源。
- **怎么做**：点标题展开，直接在里面点 **买入 / 放弃**。
- **看什么**：L0 是防守档时会显示"无买入指令"（这是纪律，不是 bug）。

#### ② 长线 Pitch（L2）
- **作用**：从机会池三重过滤出的**值得人工审批**的候选（价值/质量/事件等，持有数周~数月）。
- **每张卡看什么**：类型（quality_gap 质量折价 / value 低估值 / revalue 价值重估…）、评分、同类排名、预期空间、触发理由、风控等级、档位（core 核心 / alt 备选 / temp 临时）。
- **怎么做**：**买入** → 进入"今日买入指令"和持仓预登记；**放弃** → 留痕进历史。
- **注意**：`NO_DATA` 表示质量/估值数据不全，不代表看多或看空。

#### ③ 短线 Pitch（科技线，L2 平行支线）
- **作用**：情绪/资金短线（近 5 日涨停、连板、换手 + ATR 止损），持有 3–10 个交易日。
- **每张卡看什么**：`换手 今日X% / 5日均Y%`、涨停次数、连板、ATR 止损价。
- **怎么做**：同意就审批买入，但**必须按卡上的止损价执行**（跌破即走）。
- **注意**：这类票不做长期持有；上市不足 60 个交易日的新股技术样本不足。

#### ④ 参考 L1（明确"不产生买入指令"）
- **作用**：只做参考与排雷。
- **包含**：机会池全量（7 类机会）、机器强因子池（前 0.1%）、竞价强度、**turn_low 防守主力 top20**。
- **怎么用**：
  - 想找方向 → 看机会池里哪类机会多（今天 value 309 / quality_gap 587 / event 302…）
  - 想打底仓 → 看 turn_low top20（40 日调仓、分散、无止损，是"主力仓"参考）
  - 想排雷 → 看机器池和你手里票是否重叠、竞价是否过热

#### ⑤ 历史
- **作用**：所有审批记录（买入/放弃）留痕，复盘用。

### 3.4 三层池（纪律层，决定"买多少"）

**作用**：`output/pool_layers_*.json`，按"观察 → 候选 → 决策"三层收敛。

| 层 | 含义 | 今天的数 |
|---|---|---|
| L1 观察池 | 四因子排名 Top100（基本面硬筛：ROE≥5%、正增长、非 ST） | 100 只 |
| L2 候选池 | 技术确认：价>MA50、距 52 周高点回撤≤20%、量比≥0.8 | 取决于行情 |
| L3 决策池 | 真正可买清单（行业上限 3、资金分档）；**防守档强制清空** | 通常 0–15 只 |

**怎么做**：命令行手动刷新（日更链已含）：

```powershell
".venv\Scripts\python.exe" strategy\pool_layers.py --n 100 --capital 200000
```

**看什么**：`output/pool_layers_<时间戳>.json`，或决策页/持仓页里的"三层池"卡片。

### 3.5 持仓 `/holdings`

**作用**：你现在**真实持有**的股票（这是唯一和"你实际买入"有关的地方）。

**怎么做**：审批买入后自动登记；这里可以看 KPI（总盈亏/持仓数）、分组、点"卖出"。

**看什么**：成本价、现价、盈亏、止损价、止盈价、风险标记（BLOCK/WATCH）。

### 3.6 回测 `/backtest`（重点：它和你的持仓无关）

**作用**：用历史数据检验"某套规则"行不行。**不需要你先买入**，也不读你的持仓。

**三种用法**：

1. **看历史档案**（`/backtest` 页）：列出之前跑过的回测（净值图 + JSON）。例如
   `latest_tech3_t5_s300_20210101_20261125.json` 就是"tech3 策略 / 300 只池 / 2021–2026"的留档。
2. **页面即时跑**：`/factors` → 「回测」Tab → 选策略、股票数、区间 → 运行（或直接调接口）：
   ```
   http://127.0.0.1:8787/api/live/backtest_run?strategy=tech3&topn=5&stocks=300&start=2021-01-01&end=2026-11-25
   ```
3. **命令行**：
   ```powershell
   ".venv\Scripts\python.exe" backtest\bt_engine.py --mode classified --start 2020-01-01 --end 2025-12-31 --limit 200
   ```

**回测的口径（为什么它可信）**：T 日信号 → **T+1 执行**；佣金万 2.6 + 卖出印花税 0.05% + 滑点 0.1%；一字板买不进过滤；财报按公告日 PIT；尽量含退市股。

**看什么指标**：总收益、年化、最大回撤、夏普、胜率、超额（vs 沪深300）。例：
`tech3/300 只/2021–2026 → 总收益 −25.1%、年化 −4.8%、最大回撤 −43.6%、夏普 −0.20`。
**回测为负的策略就不要上实盘**——这是它最大的价值。

**回测与实盘的关系**：回测给"基准"，实盘结果（远期池）与基准对比 → 类型打"维持/观察/降权"。所以它间接影响你之后看到的 Pitch 卡片权重。

### 3.7 远期池 `/pitchtrack`（验证 "推荐准不准"）

**作用**：每张 Pitch 卡入池后自动跟踪 T+1 / T+5 / T+20 / T+60 收益，分 5 个池对比（长线/短线/机器/牛散/AI 精选）。

**怎么做**：日更链里自动填充（`pitch_track.py`），页面只读。

**看什么**：各池胜率、均收益、回撤；某类型连续跑输 → 系统会自动降权（Pitch 卡片带 🔻）。

### 3.8 因子池 `/factors`

**作用**：因子健康度（拥挤度/衰减/IC）、因子排名、单因子回测。
**怎么做**：只读为主；「回测」Tab 可即时跑单因子/组合。
**看什么**：因子拥挤度（过热会提示）、近 60 日 IC 是否衰减、推荐质量。

### 3.9 ETF 映射 `/etf`

**作用**：把"策略暴露"翻译成"可交易 ETF"——不想买个股时，用 ETF 复制同样的暴露。

**怎么做**：
```powershell
".venv\Scripts\python.exe" etf\etf_map.py      # 约 1 分钟，产出 output\etf_map.json
```
**看什么**：41 张 ETF pitch 卡（与策略相关性/稳定性/流动性综合分）、8 只配置建议（权重）、复制组合 vs 策略的相关性与收益。

### 3.10 五福轮动（门户卡片 / `/api/live/wufu_rotation`）

**作用**：A 股弱市时，提示切换到全球资产（黄金/纳指/日经/德国/有色/豆粕…）里动量最强的那个，属**防守建议**。
**怎么做**：日更链自动重建缓存与信号；也可手动：
```powershell
".venv\Scripts\python.exe" scripts\build_wufu_cache.py
".venv\Scripts\python.exe" factors\policy\global_rotation.py
```
**看什么**：9 只资产的 20/60 日收益、年化动量、R²、是否站上 MA10；`a_share_weak=true` 且"无轮动建议"= 全部资产都在 MA10 下方，此时结论是**持现金/减仓**。

### 3.11 日报 `/report`

**作用**：每天自动生成的复盘（市场环境 / 今日不选或选了谁 / 候选池 / 因子实测）。
**怎么做**：日更链 18:30 后自动出（`data/daily_report_auto.py --dry-run`）；也可手动跑。
**看什么**：择时分数与理由、今日是否选股（宁缺毋滥，多数日子"今日不选"）、候选池明细。

### 3.12 数据资产 `/data`

**作用**：看数据底账——各库行数、最新日期、覆盖率（bars/finance/hist_mv/unified）。
**怎么用**：只读；排查"为什么某策略没结果"时先看这里。

### 3.13 控制台 `/control`（AI 协作）

**作用**：嵌入式 DeepSeek HARNESS——让 AI 帮你审计前视、解释因子、查数据缺口、生成脚本。
**第一次用**：先打开 http://127.0.0.1:3080 新建一个对话（控制台只能续聊已有会话），再回 `/control` 对话。
**可以问什么**：
- "今天 Pitch 为什么这么少？"
- "帮我查 value 类为什么是 0 条"
- "把这三只票的止损价算一下"

## 5. 一条完整的最小闭环（照着做一遍）

> 目标：从"没数据"走到"审批一只票 + 看回测 + 验证结果"。下面用真实命令，耗时标注为实测。

### Step 0 · 启动（1 分钟）
```powershell
cd C:\DSHQuant
".venv\Scripts\python.exe" launcher.py
```
看到 `[QuantDeck] 量化系统已启动: http://127.0.0.1:8787` 即可。另开浏览器。

### Step 1 · 让数据就绪（首次 12 分钟；日常 3–4 分钟）
```powershell
# 首次：全历史（5224 只 × 2019至今，约 12 分钟）
".venv\Scripts\python.exe" scripts\pull_real_data.py
# 日常：只补最近 5 天（约 3–4 分钟）
".venv\Scripts\python.exe" scripts\pull_real_data.py --incremental
```

### Step 2 · 跑一次完整计算（约 30–38 分钟）
```powershell
".venv\Scripts\python.exe" scripts\daily_run.py --skip-fetch   # 数据刚拉过就跳过拉取
```
会依次跑：指数 → 宏观 → 估值 → 五福缓存 → 机会扫描 → Pitch → 短线池 → 三层池 → 择时 → 远期池 → 止损 → 日报 → ETF → 归档 → 自检。

**看结果**：`logs\daily_run_<时间戳>_summary.json` 里 `status: ok`、`failed: []`。

### Step 3 · 看择时（1 分钟）
打开 `/timing_dash`：记录当前档位（例：🟡 谨慎买入 43.3 分）。
→ **若 🔴 则后面只需"观察 + 回测"，不要实际下单。**

### Step 4 · 在 Pitch 里审批一只（2 分钟）
1. 打开 `/pitch` → 上方"今日买入指令"展开
2. 切到「长线」Tab，挑一张 core 档卡片（例如 `value 000027 深圳能源 99.4 core`）
3. 点 **买入**
4. 回到顶部"今日买入指令"，应看到该票状态变为"已审批"
→ 此时它才真正进入你的决策流（`/holdings` 可见预登记）。

### Step 5 · 看短线池（1 分钟）
`/pitch` →「短线」Tab：看 `换手 今日X% / 5日均Y%`、ATR 止损价。
→ 你要做的是**记住止损价**，不是无脑买。

### Step 6 · 跑一次回测（3–5 分钟，**这一步不需要你有任何持仓**）
```powershell
# 直接调接口，看某个策略在历史上的表现
Invoke-RestMethod "http://127.0.0.1:8787/api/live/backtest_run?strategy=tech3&topn=5&stocks=300&start=2021-01-01&end=2026-11-25" |
  Select-Object -ExpandProperty metrics | Format-List
```
或打开 `/backtest` 看已有档案（净值曲线 + 指标）。
→ 若年化/夏普很差，说明这类策略在你手上的历史数据里不成立，**Pitch 卡片只能当参考**。

### Step 7 · 看远期验证（1 分钟）
`/pitchtrack`：查你审批过的票在 T+1/T+5/T+20/T+60 的真实表现（刚审批的票要等几天才有数据）。

### Step 8 · 看 ETF 与五福（1 分钟）
- `/etf`：如果不想买个股，找一张与策略相关性高的 ETF 卡（例：红利/上证50），按 `recommend.weights` 配。
- 门户"五福轮动"：看是否提示防守（当前全部资产跌破 MA10 时，结论=持现金）。

### Step 9 · 问 AI 一句（可选）
`/control` → "帮我看今天 Pitch 只有 9 只的原因，按类型拆一下"。
AI 会读 `logs/opp_pool_*.json` 和阈值解释给你。

**到这里你已经走完一遍完整闭环**：数据 → 择时 → 机会池 → Pitch → 审批 → 持仓 → 回测 → 远期验证 → 辅助（ETF/五福/AI）。

## 6. 数据与产物的更新节奏

| 内容 | 更新方式 | 频率 |
|---|---|---|
| 日线 `bars.db` | `scripts/pull_real_data.py --incremental` | 每日（日更链第 1 步） |
| ST 标记 | `scripts/mark_st_current.py` | 每日（紧跟日线，否则 ST 过滤失效） |
| 估值（PE/PB/市值） | `scripts/pull_valuation_baidu.py` | 每日（约 8 分钟，可 `--skip-valuation` 降到每周） |
| 财报 | `scripts/pull_finance_ths.py` | 每季（约 30 分钟） |
| 机会池 / Pitch / 短线池 / 三层池 / 择时 / 远期池 / 日报 | `scripts/daily_run.py` | 每日 18:30（计划任务）+ 可手动 |
| 五福轮动 / ETF 映射 | 日更链内（`build_wufu_cache.py` + `global_rotation.py` + `etf_map.py`） | 每日 |
| 实时行情 / API 状态 | 页面自动请求（60s / 120s 缓存） | 实时 |

## 7. 常见问题排查

| 现象 | 先看哪里 | 处理 |
|---|---|---|
| 页面 404 / 打不开 | `logs\deck_stderr.log` | 服务没起：`启动.cmd`；端口被占：`停止.cmd` 再启动 |
| 页面数据不更新 | `scripts\check_freshness.py` | 数据日不动 = 没跑增量；跑 `daily_run.py --skip-ver...`（按需） |
| Pitch 空 / 机会池空 | `/pitch` → 参考 L1 的机会池数量 | 扫描没跑（跑 `scan.py --pitch`）；或 L0 防守档无指令 |
| `value` 类一直是 0 | `/data` 或 `finance.db.valuation` | 估值没拉：`pull_valuation_baidu.py` |
| 诊断显示 `NA · 证据不足` | 卡片里的"数据缺口" | 新股（<60 交易日）或缺估值/质量，属正常 |
| 某只票在短线池但长线池没有 | 两个体系独立 | 正常，短线只看情绪/技术，别混用 |
| HARNESS 控制台"暂不可达" | `/api/harness` | 未在 :3080 建会话；先去 3080 新建对话 |
| 回测报"缺库" | 报错文本 | `hist_mv.db` 缺失：跑 `data\build_hist_mv.py` |

## 9. 三条纪律（比任何功能都重要）

1. **L0 红档不买**（择时不合适时，卡片再好看也不动手）；
2. **短线必带止损**（卡片上的 ATR 止损价是硬线，跌破就走，不"再看看"）；
3. **主力仓走 turn_low 分散，Pitch 只做卫星**（高分集中持仓的回撤实测 −41%~−60%）。
