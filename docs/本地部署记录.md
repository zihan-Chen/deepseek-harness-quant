## 二、环境（为什么是独立 venv）

本机有三套 Python，直接 `python` 会踩坑：

| 解释器 | 情况 | 结论 |
|---|---|---|
| `C:\python-3.14.10-embed-amd64\python.exe`（PATH 默认） | 嵌入式版，**无 pip、无第三方包** | ❌ 不能用 |
| `C:\Users\...\miniconda3\python.exe` | conda base，依赖齐全（pandas 3.1.1 等），但属 conda 环境，且与系统包混装 | ⚠️ 不采用 |
| `C:\Users\...\Programs\Python\Python314\python.exe` | 干净的正式版 3.14.10 | ✅ 用它的 venv |

因此部署在仓库内建独立环境，后续启动一律走绝对路径，不受 PATH/conda 激活影响：

```powershell
# 已完成，无需重复执行
C:\Users\Administrator\AppData\Local\Programs\Python\Python314\python.exe -m venv .venv
.venv\Scripts\python.exe -m pip install -r requirements.txt
```

关键版本：pandas 3.1.1 · numpy 2.5.5 · scipy 1.18.1 · tushare 1.4.29 · akshare 1.20.70 ·
baostock 0.9.4 · backtrader 1.9.78.123 · vectorbt 1.2.1 · quantstats 0.0.86 · PyYAML 6.0.4
（`docs/快速开始.md` 建议 3.10–3.12，实测 3.14 + 上述版本导入/回测引擎均正常）

Node：官方便携版 **v24.22.3** 解压到 `runtime\node\`（`launcher.py` 会优先找这里），
HARNESS 运行时为 `harness\node_modules\@deepseek-ai\dsh@0.1.0-rc.6`，`DSH_HOME=harness\home`。

### 8.1 数据源选择（实测对比）

| 源 | 接口 | 实测 | 结论 |

### 8.2 入库口径（校验过的三点）

- 复权：`adjust="qfq"`；最新交易日收盘价与 baostock 一致（`600036` 差 0）；
  历史段两家除权因子基准不同（`600036` 最大差 5.70 元），因此**全市场统一用腾讯入库，不与 baostock 样本混放**。
- 单位：`volume=股`、`amount=元`（与 baostock 相同），写入 `source="akshare"` 不触发千元/手换算。
- 换手率：腾讯 `turnover` 是小数（`0.0027`=0.27%），入库 ×100 对齐 `bars.db` 的 `turn`(%)。
- `is_st` 置 0（腾讯无 ST 字段），待 `fix_st_flags.py` 回填。
